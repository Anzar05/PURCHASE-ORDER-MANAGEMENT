# PURCHASE-ORDER-MANAGEMENT
SAP - ABAP PROJECT ON PURCHASE ORDER MANAGEMENT 


A SAP ABAP-based Purchase Order Management System developed to retrieve, process, and display purchase order details using ALV reports. The project uses standard SAP tables such as EKKO, EKPO, and LFA1 and includes selection screens, internal tables, Open SQL, vendor-wise data, total amount calculation, and delivery status.

🛠️ Technologies

SAP ABAP | SAP GUI | ALV | Open SQL | Internal Tables | Selection Screens
